# Galaga Game

A desktop recreation of the classic **Galaga arcade game**, developed in Java using the **JavaFX** framework. This project replicates the core mechanics of the original — spaceship control, enemy waves, shooting, collisions, and scoring — in a modern Java environment.

---

## 🎮 Overview

This is a school/learning project designed to demonstrate:

- Object-oriented game development
- JavaFX for GUI and animations
- Collision detection and game loop management
- Game asset rendering (player, enemies, bullets)

---

## 🧩 Features

- 🛸 Controllable player spaceship 
- 🚀 Shoot bullets to destroy incoming enemies
- 👾 Animated enemy waves with movement patterns
- 💥 Collision detection between player/enemies and bullets
- 🔄 Game restart functionality
- 🧮 Scoring system
- 🎨 Custom graphics via PNG sprites

---

## 🧰 Tech Stack

- **Language**: Java
- **Framework**: JavaFX
- **Build Tool**: Maven
